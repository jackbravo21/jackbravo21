Primeiro vc cria o model, e depois da um migrate, apos construir a tabela.

composer create-project --prefer-dist laravel/laravel blog "5.5.*"
$ php artisan make:auth						//cria authenticacao.
$ php artisan make:model Curso -m
$ php artisan make:migration nome
(assim que se faz para criar uma nova migracao com a estrutura pronta para criar os campos/parametros dos produtos)
$ php artisan make:migration produtos_table --create=produtos	//digo para ele criar e o nome da tabela que eu quero com --create.
$ php artisan migrate
$ php artisan migrate:rollback					//volta o ultimo passo executado da migracao.
$ php artisan migrate:fresh					//apaga dando drop em todas as tabelas, o conteudo.
$ php artisan migrate:refresh					//(migranovamente) da rollback em tudo, mas nao apaga os dados, e migra novamente.
$ php artisan migrate:refresh --step=2				// volta apenas 2 passos.
$ php artisan make:controller nome
$ php artisan make:controller CommentsController -r		//o R ja cria o controller com as funcoes basicas.
$ php artisan make:seeder NomedoSeeder				//cria as semeadoras.
$ php artisan migrate:seed
$ php artisan migrate:refresh --seed
$ php artisan migrate:reset					//reverte as configuracoes.
$ php artisan key:generate 					//gera nova chave de seguranca.

Laravel docs migrations vc consegue ver os tipos de dados.

O model vai ficar na pasta APP, e ja vem com modelo padrao "User.php".

Devo criar um modelo para cada tabela.

Para criar um modelo eu devo dar um comando artisan, e se eu quiser que ele ja venha com a migration, eu adiciono um -m:

>php artisan make:model Contato -m		//Contato eh o modelo novo que ele vai criar o arquivo.

Comando para criar uma nova migracao, e criando automatico, eu coloco --create=nome_da_nova_tabela:

>php artisan make:migration create_produtos_table --create=produtos

Para rodar as migracoes e gerar todas as tabelas:

>php artisan migrate

Para dar rollback no banco basta dar o reset:

>php artisan migrate:reset
