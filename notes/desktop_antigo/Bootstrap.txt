usar node em uma pasta:
- ir ate a pasta pelo cmd, e digitar "npm init", enter...

instalar o bootstrap e o Jquery e o javascrip:
- ir ate a pasta pelo cmd.
- npm install bootstrap					//boostrap
- npm install jquery					//jquery
- npm install popper.js					//popper.js

- npm install font-awesome				//fonts do "https://fontawesome.com/"

instalar no windows SASS:
npm install -g sass

Versao SASS:
sass --version

Copilar com SASS:
sass --watch node_modules/bootstrap/scss:node_modules/bootstrap/copiler		//pasta onde estao:pasta destino

sass --watch node_modules/bootstrap/scss:node_modules/bootstrap/copiler node_modules/font-awesome/scss:node_modules/font-awesome/css style/scss:style/css

<div class="container"></div> = cria uma especie de cercado, tabela, aquelas antigas

Para fixar no top, usar na classe: "fixed-top"
Para fixar no rodape, usar na classe: "fixed-bottom"

ml-1a5 = margem left
mr-1a5 = margem right
mb-1a5 = margem bottom
mt-1a5 = margem top
my-1a5 = margem  em todo eixo Y da pagina

Exemplo de uso para: col-sm-6 col-md-4
col-xs-6 = super small tem que ficar no tamanho 6.
col-sm-6 = small tem que ficar no tamanho 6.
col-md-4 = medium tem que ficar no tamanho 4.
col-lg-4 = large tem que ficar no tamanho 4.

justify-content-center = para centralizar algo
justify-content-sm-center = para centralizar algo, o sm eh o tamanho.
font-weight-bold = negrito

<p class="text-center"></p> = centraliza o texto.
Exemplo: <div class="col-12 text-center"></div>

<h1 class="display-4"></h1> = display aumenta o texto.
<p class="lead"> = aumenta o texto.
