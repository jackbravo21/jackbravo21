

Todo JS eh posto dentro do <script></script>:

=============================================

<script>

...
</script>

=============================================

Pode ser utilizado dentro do <body> ou <head>.



Para escrever com JS se usa a funcao "document.write", document.write("Codigo"), assim:

=============================================

<script>

document.write("Hellow World!");

</script>

=============================================



Pode ser usado tags para ajustar o texto com html:

=============================================

<script>

document.write("<h1>Hellow World!</h1>");

</script>


=============================================



A tag <script> pode ter dois atributos, "language" e "type":

=============================================

<script language="javascript" type="text/javascript">
</script>

=============================================





ALERT BOX:

Para escrever uma mensagem em um alert box:

=============================================

	<script type="text/javascript">

	</script>

=============================================

Variavels:

variaveis sao container que contem valores de dados.
Variaveis podem ser mudadas durante o programa e atribuida valores.
Atribuimos a variavel com "var" o nome dela, e o valor que ela recebe;

=============================================

var x = 10;

=============================================




O valor de igual (=) eh chamado "assignment" operator, diferente do "igual a".
Pode fazer um valor receber outro, ou receber outras variaveis, como "x = y".
Quando a variavel nao recebe um valor, ela recebe a propriedade "undefined".

=============================================

var x;

documment.write(x);

//usar o console e digitar x;
//resultado: undefined;

=============================================

Passamos o valor para a variavel e escrevemos ela;

=============================================

NOME DE VARIAVEIS:

No JavaScript os nomes das variaveis sao case-sensitive.

Regras:
- Primeiro caractere deve ser letra ou underscore (_), ou dollar ($).
- Numeros nao podem ser usados no primeiro caractere.
- Nomes de variaveis nao podem incluir operadores ou caracteres especiais, ERRADO "2*algumacoisa" ou "this+isso".
- Nao pode conter espacos.

Incremento e Decremento:

=============================================

Operator:	Descricao:		Exemplo:				Resultado:

var++		Pos Incremento		var a = 0, b = 10, var a = b++;		a = 10 and b = 11;
++var		Pre Incremento		var a = 0, b = 10, var a = ++b;		a = 11 and b = 11;
var--		Pos Decremento		var a = 0, b = 10, var a = b--;		a = 10 and b = 9;
--var		Pre Decremento		var a = 0, b = 10, var a = --b;		a = 9 and b = 9;



Operador:	Exemplo:		Equivalente a:

=		x = y			x = y
+=		x += y			x = x + y
-=		x -= y			x = x - y
*=		x *= y			x = x * y
/=		x /= y			x = x / y
%=		x %= y			x = x % y

=============================================





Operadores de comparacao, igual a (==) verifica se os valores sao iguais:

=============================================

Operador:	Igual a:			Exemplo:

==		Igual a				5 == 10 false
===		Identico ou mesmo tipo		5 === 10 false
!=		Diferente de			5 != 10 true
!==		Nao identico			10 !== 10 false
>		Maior que			10 > 5 true
>=		Maior ou igual			10 >= 5 true
<		Menor que			10 < 5 false
<=		Menor ou igual			10 <= 5 false

=============================================




Operadores Logicos sao como Boolean, retorna com (true ou false):

=============================================

&&	E	Retorna verdadeiro se as duas condicoes sao verdadeiras, se uma for false, retorna falso.
||	OU	Retorna verdadeiro se apenas um dos valores for verdadeiro.
!	Nao	Retorna o valor contrario do obtido.

=============================================





Operadores:

=============================================

(4>2) && (10>5);	//verdadeiro;
(4>2) && (10<5);	//falso;
(4>2) || (10>5);	//verdadeiro;
(4>2) || (10<5);	//verdadeiro;
!(4>2) && !(10>5);	//falso;
!(4>2) || !(10>5);	//falso;

}

function getRandomIntInclusive(min, max) {
  min = Math.ceil(min);
  max = Math.floor(max);

The DOM (Document Object Model):
---------------------------------------------

Quando abrimos uma pagina web no navegador, o HTML da pagina eh carregado e renderizado visualmente na tela.

Os elementos HTML representam nos/nodes em uma arvore. Todos os nos tem uma relacao com os outros.

	 <title>	       <h1>		     <a>

<body> tem dois filhos (<h1> e <a>) e um pai (<html>);

Propagacao de evento:

Temos duas maneiras de eventos de propagacao com HTML DOM:
"bubbling" e "capturing".

O Evento de propagacao permite a definicao dos elementos ordenando quando um evento ocorre.
Se vc tem um elemento <p> dentro de um <div>, e vc usa "clicks" no elemento <p>, quais eventos "click" voce deve tratar primeiro?

In "Bubbling", o evento mais intimo dos elementos deve ser manipulado primeiro e depois manipula-se o mais externo.
O elemento <p> do evento click eh manipulado primeiro, seguido pelo elemento <div> com evento Click.

Em "Capturing", o evento do elemento mais externo é tratado primeiro e depois o interno. O evento de clique do elemento <div> é tratado primeiro, seguido pelo evento de clique do elemento <p>.

Capturing vai "down" a DOM.
Bibbling vai "up" a DOM.

Um paragrafo que esta dentro do elemento div, e vc quer o evento click do paragrafo para manipular primeiro, vc usa o Bubbling.

---------------------------------------------
=============================================





Capturing vs. Bubbling:

O metodo "addEventListener()" permite especificar o tipo de propagação com o parametro "useCapture".

---------------------------------------------

Ex.:

addEventListener(event, function, useCapture);

---------------------------------------------

O valor default eh "falso", o que significa que a propagação de bolhas é usada, quando o valor é definido como "verdadeiro", o evento usa a propagação de captura.

---------------------------------------------

Ex.:

//Capturing propagation
	elem1.addEventListener("click", myFunction, true);

//Bubbling propagation
	elem2.addEventListener("click", myFunction, false);


//Isso é particularmente útil quando você tem o mesmo evento manipulado para vários elementos na hierarquia do DOM.

---------------------------------------------

//Manipular o evento click e use a propagacao de captura.

x.addEventListener("click", func, true);

Form Validation:

---------------------------------------------

O HTML5 adiciona alguns atributos que permitem a validação de formulário. Por exemplo, o atributo "required" pode ser adicionado a um campo de entrada para tornar obrigatório o preenchimento.
A validação de formulário mais complexa pode ser feita usando JavaScript.
O elemento do formulário possui um evento "onsubmit" que pode ser manipulado para executar a validação.
Por exemplo, vamos criar um formulário com duas entradas e um botão. O texto nos dois campos deve ser o mesmo e não estar em branco para passar na validação.

---------------------------------------------

<form onsubmit="return validate()" method="post">
	Number:
	<input type="text" name="num1" id="num1" />
	<br>
	Repeat:
	<input type="text" name="num2" id="num2"/>
	<br>
	<input type="submit" value="Submit" />
</form>

---------------------------------------------

//Agora precisamosdefinir a funcao "validate()":

function validate(){

	var n1 = document.getElementById("num1");
	var n2 = document.getElementById("num2");
	
	if(n1.value != "" && n2.value != ""){

	if(n1.value == n2.value){

	return true;
	}
	}
	
	alert("The values should be equal and not blank");

	return false;
}

//Retornamos true somente quando os valores não estão em branco e são iguais.

Var & Let

Em ES6 temos tres formas de declarar as variaveis:

---------------------------------------------

var a = 10;
const b = 'hello';
let c = true;

---------------------------------------------

O tipo de delcaracao usada depende do escopo necessario. Scopo eh o conceito fundamental em todas as linguagens de programacao, que definem a visibilidade da variavel.







var & ler:

Ao contrario da palavra chave var, que define uma variavel globalmente ou localmente para a funcao inteira, indpendente do escopo do bloco, permite declarar variaveis com escopo limitado ao bloco, instrucao ou expressao em que sao usadas.

---------------------------------------------

//Ex.:

if(true){

	let name = "Jack";

}

alert(name);	//generates an error.

---------------------------------------------

Neste caso, o nome variavel eh acessivel apenas neste escopo do "if" por que foi declarado como "let".

Para demonstrar de forma diferente no escopo da declaracao var e let, considere o seguinte exemplo:

---------------------------------------------

function varTest(){

	var x = 1;

	if(true){

	var x = 2;		//same variable.
	console.log(x);		//2.
	}

	console.log(x);		//2.
}

function letTest(){

	let x = 1;
	
	if(true){
	let x = 2;		//variavel diferente.
	console.log(x);		//2.
	}

	console.log(x);		//1.
}

---------------------------------------------

Uma das melhores maneiras de usar o "let" eh em loops:

---------------------------------------------

for (let i=0; i<3; i++){

	document.write(i);

} 

---------------------------------------------

Aqui a variavel "i" esta acessivel apenas no escopo do loop "for", onde eh necessario.

OBS.: let não está sujeito a icamento variavel, o que significa que as declarações let nao se movem para o topo do contexto de execucão atual.

---------------------------------------------

Ex1.:

function letItBe() {
  let v = 2;
  if (true) {
    let v = 4;  
    console.log(v); 
  }
  console.log(v); 
}
letItBe();

//4 2.

Const:
---------------------------------------------

As variaveis const tem o mesmo escopo que as variaveis declaradas usando ler. A diferenca eh que as variaveis const sao imutaveis - elas nao podem ser reatribuidas.
Por exemplo, o seguinte gera uma excecao:

---------------------------------------------

const a = 'Hello';
a = 'Bye';

---------------------------------------------

const também não está sujeito a Variable Hoist, o que significa que as declarações const não se movem para o topo do contexto de execução atual.
Observe também que o código ES6 será executado apenas nos navegadores que o suportam. Dispositivos e navegadores mais antigos que não oferecem suporte ao ES6 retornarão um erro de sintaxe.

---------------------------------------------

Ex.: to make a constant named total and the variable i that is only accessible inside the loop.
  
const total = 100;
let sum = 0;

for(let i = 0; i < total; i++) {
  sum += i;
}

Literais de modelo no ES6

Literais de modelos sao uma maneira de gerar vaiveis na string.
Antes do ES6, tivemos que quebrar a string, por exemplo:

---------------------------------------------

let name 'David';
let msg = 'Welcome' + name + '!';
console.log(msg);

---------------------------------------------

O ES6 apresenta uma nova maneira de gerar valores variaveis em strings. O mesmo codigo acima pode ser reescrito como:

---------------------------------------------

let name = 'David';
let msg = 'Welcome ${name}!';
console.log(msg);

---------------------------------------------

Observe que os literais do modelo são delimitados pelo caractere backtick (``) em vez de aspas simples ou duplas.
A $ {expression} é um espaço reservado e pode incluir qualquer expressão que será avaliada e inserida no modelo literal.

---------------------------------------------

//Por exemplo:

let a = 8;
let b = 34;
let msg = `The sum is ${a+b}`;
console.log(msg);

//Para escapar de um backtick em um literal de modelo, coloque uma barra invertida \ antes do backtick.

---------------------------------------------

//To output "We are learning ES6!".

let n = 6;
let s = 'ES';
let msg = `We are learning 
 
$
 
{s + n}!`;
console.log(
 
msg
 
);
