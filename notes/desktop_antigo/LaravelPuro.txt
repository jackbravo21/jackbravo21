Vamos criar um novo controlador "ClienteControllador" com "resource", que vai fazer com que o controllador seja criado com varios metodos, cada um responsavel por fazer alguma coisa..
- php artisan make:controller ClienteControllador --resource

- index: O metodo "index" eh utilizado para quando vc quer acessar determinada rota e mostrar, listar, todos os seus clientes.

- create: Quando vc tem o botao e quer abrir um formulario para criar um novo cliente.

- store: Eh para quando vc esta no formulario, o cara digita o nome do novo cliente, quando vc quer salvar o novo cliente, voce vai direcionar o post do novo cliente para este Store.

- show: eh para quando vc quer ver alguma informacao de determinado cliente, alguns dados a mais.

- edit: eh para quando la na lista de clientes vc clica em um botao, dizendo que quer editar as informacoes de um determinado cliente, esse link vai apontar para este metodo, recebendo um id vai carregar um formulario com os dados deste cliente, e vai apontar para o update.

- update: quando quiser salvar o novo cliente, ou os dados do cliente editado, vai apontar para o medoto update que vai efetivar e salvar as informacoes do formulario.

- destroy: quando vc esta na lista de clientes e vc quer apagar/deletar determinado usuario, vc clica no botao excluir, ele vai apagar o usuario da tabela do db, ele vai direcionar para este metodo passando o ID.

Primeiro passo, eh associar as rotas que queremos tratar, ao nosso controlador.
Precisariamos no minimo usar 7 linhas de codigo para associar no "web.php" aos metodos de uma rota especifica de um determinado controllador.
No entanto o Laravel ja tem a funcao "Route::resource", porem ficaria assim, pela logica:
Por exemplo:
	/clientes 		: chamaria "index()";
	/clientes/novo		: chamaria "create()";
	/clientes/post		: chamaria "store()";
	/clientes/indice&id	: chamaria "show($id)"; Exibiria informacoes de um determinado cliente.
	/clientes/edit&id	: chamaria "edite($id)"; Chamaria tambem um formulario com a edicao do cliente especifico do ID passado.

O Laravel ja fornece uma funcao atraves do Route::resource, que atraves do controllador ele usa todos os metodos, sem precisar chamar um por um.
