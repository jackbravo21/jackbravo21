.mvm
- Onde ficam as conviguracoes do maven.

@SpringBootApplication
- Eh a porta de entrada de config do spring boot

@Configuration
- Vai definir que a nossa classe pode ter métodos que definem beans;

@EnableConfiguration
- Classe que ativa a auto configuração do spring boot, o springboot saiba que estamos fazendo configurações automaticas;

@ComponentScan
- Vai scanear o pacote em busca de tudo, de controladores, componentes, etc.

@RestController
- Indica que minha classe eh um controller rest, ou seja, combinando as anotações da @Controller e @ResponseBody;

@RequestMapping("/hello-word")
- Eh a rota;

@GetMapping
- Eh o route.get que vai responder no hello-word;

@GetMapping("/get")
- Responde para além da raiz do hello-word/get;


localhost:8080/


- Alterar a porta:
/resources/aplication.properties
- Devo criar a linha:
server.port=9000

- Também posso usar o "/resources/aplication.properties" para logar no banco de dados com:
spring.datasource.url=jdbc:mysql://localhost:3306/first_spring_app
spring.datasource.username=root
spring.datasource.password=""

@Profile("dev")
- posso criar uma 'application-dev.properties', e posso dizer no 'application.properties' qual esta ativo com a linha:
spring.profiles.active=dev
- ou:
spring.profiles.active=${ACTIVE_PROFILE:dev}



@Service
- Anotation para indicar que a classe eh um service;


- Para criar um método construtor, ele deve ser publico, com o mesmo nome da classe;

@Autowired
private HelloWordService hellowWorldService;
- Falo que a dependência vai ser injetada, com o Autowired;

@Bean
- Eu uso dentro das classes que tem o @Configuration, para indicar para o spring que ele deve gerenciar o retorno do método como um Bean da aplicação;
- Implementa uma classe externa que vem de terceiros, mapeando os métodos que estão com @Bean;


@Getter
@Setter
@AllArgsConstructor
- Anotações para getters and setters;


@PostMapping("/{id}")
public String helloWordPost(@PathVariable("id") String id, @RequestBody User body) {
return "Hello Word Post " + body.getName() + id;
}


@PostMapping("/param/{id}")
public String helloWordPost(@PathVariable("id") String id, @RequestParam(value = "filter", defaultValue="nenhum") String filter, @RequestBody User body) {
return "Hello Word Post " + body.getName() + id + filter;
}
