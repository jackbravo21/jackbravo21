Para capturar um parâmetro do URL, devemos usar a superglobal "$_GET".

Parametro no link fonte:
<ul>
<li><a href="destino.php?codigo=0">Laranja</a></li>
<li><a href="destino.php?codigo=1">Maca</a></li>
<li><a href="destino.php?codigo=2">Abacate</a></li>
</ul>

Parametro no destino:
<?php
	$fruta = $_GET["codigo"];
	echo $fruta;
?>

Podemos acrescentar um array tb:

<?php
	$salada = array("Laranja","Maca", "Abacate");
	$fruta = $_GET["codigo"];
	echo $salada[$fruta];
?>

E então, adicionamos os links:

<?php
	$salada = array("imagens/laranja.jpg","imagens/maca.jpg", "imagens/abacate.jpg");
	$fruta = $_GET["codigo"];
	echo $salada[$fruta];
?>

Depois excluo a linha echo e crio um img com o mesmo echo:

<?php
	$salada = array("imagens/laranja.jpg","imagens/maca.jpg", "imagens/abacate.jpg");
	$fruta = $_GET["codigo"];
?>
<img src="<?php echo $salada[$fruta]; ?>" >

Metodo GET e POST:

- GET = aparece no URL o valor capturado.
- POST = nao aparece o valor capturado, usado para sistemas de login, por exemplo.

==============================================================
==============================================================
Para passar informações escondidas da url, a sua requisição precisa ser do tipo Post. O problema é que muitas vezes quando vamos fazer um comportamento na tela como um deletar, colocamos aquela tag <a> para fazer um hyperlink que o usuário apenas clica. E por especificação do HTML, o <a href="..."> é sempre do tipo Get, então os parâmetros acabam indo na url.
Um jeito de contornar isso é você fazer com que o seu hyperlink esteja dentro de um form do tipo Post, os parâmetros que você quer enviar são inputs do tipo hidden e que o form será disparado quando o usuário clica no hyperlink. Tem este link com um exemplo de como isso pode ser feito.

Clausulas de consulta:

SELECT:		Seleciona as colunas que participarao da consulta.
FROM:		Seleciona as tabelas que selecionarao as colunas.
WHERE:		Utilizada para especificar filtros e condicoes.
GROUP BY :	Utilizada para agrupar conjuntos de dados.
HAVING :	Utilizada para expressar a condicao que deve satisfazer cada grupo.
ORDER BY :	Utilizada para ordenar os registros selecionados com uma ordem.
DISTINCT :	Utilizada para selecionar dados sem repeticao.


- SEGUIR DEMPRE A MESMA ORDEM:

EX. consulta:

SELECT 	nomeproduto, precounitario, tempoentrega	(colunas)
FROM	produtos					(tabela)


Retornar quantos tempos de entrega eu tenho dentro do banco com "DISTINCT":

SELECT 	DISTINCT tempoentrega				(colunas)
FROM	produtos					(tabela)


Pegar um numero limite de resultados:

SELECT 	nomeproduto, precounitario, tempoentrega	(colunas)
FROM	produtos					(tabela)
LIMIT	10						(limita o numero de registros que vc quer que apareca)


Ordenacao em ordem crescente:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
ORDER BY 	produtoID					(ordena)
LIMIT	10							(limita o numero de registros que vc quer que apareca)

Ordenacao em ordem decrescente:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
ORDER BY 	produtoID	DESC				(ordena em decrecente)
LIMIT	10							(limita o numero de registros que vc quer que apareca)

Ordenacao em ordem alfabetica:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
ORDER BY 	produtoID	ASC				(ordena alfaberico)
LIMIT	10							(limita o numero de registros que vc quer que apareca)

Ordenacao em ordem alfabetica:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
ORDER BY 	precounitario	ASC, tempoentrega ASC		(se houver embate em produtos de mesmo preco, ele usa o criterio tempo de 												entrega mais baixo)

Ordenacao em ordem alfabetica:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
ORDER BY 	precounitario	ASC, tempoentrega ASC		(se houver embate em produtos de mesmo preco, ele usa o criterio tempo de 												entrega)

FILTROS (WHERE):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		tempoentrega = 5				(exibe produtos que sao entregues apenas com a data de 5 dias)


FILTROS (WHERE) com outra selecao (AND):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		tempoentrega = 5 AND precounitario = 12		(exibe produtos que sao entregues apenas com a data de 5 dias e preco=12)

FILTROS com preco unitario menor que 12:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		precounitario < 12				(mostra produtos que tem preco unitario menor que 12)

FILTROS com preco unitario menor ou igual que 12:

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		precounitario <= 12				(mostra produtos que tem preco unitario menor ou igual a 12)

FILTROS com preco unitario entre 5 e 12 (BETWEEN, AND):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		precounitario BETWEEN 5 AND 12			(mostra produtos que tem preco entre 5 e 12)
ORDER BY	precounitario ASC				(mostra em ordem crescente)


FILTROS com tempo de entrega igual a 5 ou 30 (OR):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		tempoentrega = 5 OR tempoentrega = 30		(vai mostrar produtos com tempo de entrega igual a 5 e 30)

FILTROS com tempo de entrega igual a 5, 15 e 30 (IN):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		tempoentrega IN	(5,15,30)			(vai mostrar produtos com tempo de entrega igual a 5, 15 e 30)

FILTROS EXCLUINDO com tempo de entrega igual a 5, 15 e 30 (NOT IN):

SELECT 		nomeproduto, precounitario, tempoentrega	(colunas)
FROM		produtos					(tabela)
WHERE		tempoentrega NOT IN	(5,15,30)		(vai mostrar produtos excluindo o tempo de entrega igual a 5, 15 e 30)

FILTROS que terminem com letras mug (LIKE "%mug") [% eh igual a *]:

SELECT 		nomeproduto					(colunas)
FROM		produtos					(tabela)
WHERE		nomedoproduto LIKE "%mug"			(vai exibir todos os produtos que terminem com "mug").

FILTROS que contenha letras BLEND (LIKE "%BLEND%") [% eh igual a *]:

SELECT 		nomeproduto					(colunas)
FROM		produtos					(tabela)
WHERE		nomedoproduto LIKE "%BLEND%"			(vai exibir todos os produtos que contenham em algum lugar da palavra "BLEND").

Mostrar produto com menor preco (Min) e chamar ele de um nome (as):

SELECT 		Min(precounitario) as menorpreco		(colunas)
FROM		produtos					(tabela)
 

Mostrar produto com maior preco (Max) e chamar ele de um nome (as):

SELECT 		Max(precounitario) as maiorpreco		(colunas)
FROM		produtos					(tabela)

Mostrar produto com preco MEDIO (AVG) e chamar ele de um nome (as):

SELECT 		AVG(precounitario) as precomedio		(colunas)
FROM		produtos					(tabela)

SELECT 	count(produtoID) as total					(colunas)

SELECT 		tempoentrega, count(produtoID) as total				(colunas)

SELECT 		tempoentrega, count(produtoID) as total				(colunas)

HAVING 		total >= 5

SELECT 		nomeproduto, nomefornecedor

SELECT 		nomeproduto, nomefornecedor
FROM 		produtos AS p 						(Ele aceita tambem soh o: nomeproduto, nomefornecedor)

		ON p.fornecedorID = f.fornecedoresID			(Ele aceita tambem soh o: ON p.fornecedorID = f.fornecedoresID)
