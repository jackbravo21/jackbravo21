Diferenca do "include" para o "required":

Required = Obriga que o arquivo exista, e exige que o arquivo esteja funcionando corretamente.

Include = O include tenta funcionar, mesmo que o arquivo nao exista ou tenha algum problema. O include tambem permite que ele traga o arquivo ate mesmo da internet.

=============

(se nao existir ele tenta igual executar)
include "arquivo.php";
include "inc/arquivo.php";
include "../inc/arquivo.php";
include "../../inc/arquivo.php";

(obriga que o arquivo exista e esteja funcionando)
require "arquivo.php";

(tras uma vez soh)
require_once "arquivo.php";

Classes e objetos:

Classes possuem caracteristicas e objetos com atributos dentro delas.

Classes, encontra-se dentro dela variaveis e funcoes que ganham recursos a mais, atributos e metodos, conjunto de tudo isso.

O USO DE ";" NO FINAL DA CLASSE EH OPCIONAL!

O que eu preciso armazenar, eu coloco em atributos.

E o que eu preciso armazenar, eu coloco nos metodos.

Encapsulamento vc faz o controle de acesso a quem pode e tem acesso a essas classes e atributos.

Variaveis = atributos;

Funcoes = Metodo.

Objeto = eh uma variavel que representa ou tira uma copia da classe. Uma variavel que representa uma classe. E esse processo eh uma instancia.

Instancia = eh quando efetivamente eu vou usar esta classe.

//"->" acessa metodos normais;
//"::" acessa metodos estaticos;

O "->" tem a função de acessar atributos e métodos na Orientação a Objetos

Exemplo: sala de aula, vc bate na porta e quer falar com um aluno pedrinho, vc nao pode abrir a porta e chamar o pedrinho, deve-se chamar o professor que representa aquela classe e pedir para falar com o pedrinho, entao o professor chama o pedrinho, e ae ele está autorizado a falar comigo.
O professor eh a classe, e o pedrinho eh o objeto.
Instanciar eh criar um objeto, por exemplo um professor.
Objeto tal, instancia em tal classe.


$sql = new sql;


O "->" no PHP tem a mesma função do "." no Java que é utilizado por uma instância (objeto) para acessar um método ou uma propriedade de uma classe.

Exatamente! Tanto pelas instâncias para acessar métodos ou propriedades públicas como pelo comando interno$this para acessar atributos e métodos dentro de outros métodos.

    //Java
    this.nome
     
    //PHP
    $this->nome

Tipos de Metodos de acesso (que podem acessar atributos e metodos):
- Mesma classe, classe extendida, mesmo objeto.

Quando eh Publico: Todo mundo ve, mesma classe, classe extendida, mesmo objeto.
Quando eh Protegido: Mesma classe, classe extendida.
Quando eh privado: Soh na mesma classe.

O metodo "verDados" esta na mesma classe, vai enchergar tudo que eh publico, protegido ou privado.

Buscando em múltiplos diretórios com apenas um spl_autoload
· Aula 50


Para o caso de termos múltiplos diretórios com as classes da para buscar em todos diretórios com apenas um spl_autoload_register usando uma array e foreach.

    spl_autoload_register(function($class) {
      
      $paths = ['models', 'controllers', 'libraries'];
      
      foreach ($paths as $path) {
        if (file_exists($path . DIRECTORY_SEPARATOR . $class . ".php")) {
          require_once($path . DIRECTORY_SEPARATOR . $class . ".php");
        }
      }
    });

 <?php

//classe vai extender de PDO e pode usar todos os metodos publicos (bind, parametro, tudo);
class Sql extends PDO{

	private $conn;

	public function __construct(){

		$this->conn = new PDO("mysql:dbname=jackbravo2109; host=mysql07-farm60.kinghost.net", "jackbravo2109", "m123456m");
	}

	
	//criado depois da funcao query
	private function setParams($statment, $parameters = array()){
	
		//vamos percorres os parametros
		foreach ($parameters as $key => $value) {
			
			$this->setParam($key, $value);
		}

	}

	//criado depois do setParams acima
	private function setParam($statment, $key, $value){

		$statment->bindParam($key, $value);
	}

	//para executar comandos la, para isso usa o metodo; rawQuery = query bruta (que sera tratada depois), e receber parametros em array;
	public function query($rawQuery, $params = array()){

		$stmt = $this->conn->prepare($rawQuery);

		//passo os dados da variavel stmt, e os parametros que ela espera;
		$this->setParams($stmt, $params);

		$stmt->execute();

		return $stmt;
	}

	//select para retornar consulta do banco, retorna como array;
	public function select($rawQuery, $params = array()):array{

		$stmt = $this->query($rawQuery, $params);

		//para ver soh os dados associativos, sem os numeros;
		return $stmt->fetchAll(PDO::FETCH_ASSOC);

	}

}
