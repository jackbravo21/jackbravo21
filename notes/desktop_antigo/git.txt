BitBucket: mais reservado.


Copiar um projeto do GITHUB:

$ git clone "link/url"

ou

$ git clone +link +"o nome da pasta que eu quiser"

===================================================

Transformar uma pasta como repositório git:

- Vou ate a pasta pelo cmd, ou abro ela com o GIT, botao direito e digito comando:

$ git init

===================================================

Adicionar o arquivo no GIT (index.php é o arquivo):

$ git add index.php


===================================================

Comando para sincronizar as alteracoes de todos os arquivos da pasta no "stage area" (ele vai add ou excluir arquivos que foram incluidos ou removidos no projeto):

$ git add --all


===================================================

Enviar o arquivo para o StageArea (ele vai pedir um comentario, motivo):

$ git commit -m "criei meu repositorio"

===================================================

Meu repositorio teste, ele segue um padrao:

https://github.com/jackbravo21/teste.git

===================================================

Setar para qual repositorio eu vou enviar:

$ git remote add origin https://github.com/jackbravo21/teste.git

===================================================

Setar qual eh o seu nome, toda a vez que fizer o commit, vai atrelar ao usuario:

$ git config --global user.name "Joao Teste"

===================================================

Agora setar o email do GITHUB:

$ git config --global user.email "suporte@teste.com.br"

===================================================

Vou enviar para o servidor do GITHUB:

$ git push origin master

E apos dar enter, ele vai pedir usuario e senha, que eh o email e a senha.

===================================================

Atualizar na minha máquina, baixando do GIT repositório:

$ git pull origin master

===================================================

Estando o arquivo adicionado ja, pode-se usar soh os comandos:

$ git add --all
$ git commit -m "comentario"

===================================================

Mudar de Branch:

$ git checkout new_branch
